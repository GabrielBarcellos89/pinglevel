# Link — expansão visual v1

Novas poses oficiais para reduzir a repetição visual na plataforma PingLevel.

## Arquivos e uso recomendado

- `link-observando-rede.png`: descoberta, perguntas, análise de topologia e introdução de conceitos.
- `link-conectando.png`: atividades de conexão, montagem de rede e associação entre equipamentos.
- `link-explicando.png`: explicações teóricas, resumos e apresentação de novos conteúdos.
- `link-recebendo-xp.png`: conclusão de aula, ganho de XP e feedback de progresso.

## Diretriz de uso

Use no máximo uma pose principal do Link por etapa. Alterne as imagens de acordo com a função pedagógica da tela, evitando repetir a pose `link-v2-ensinando.png` em etapas consecutivas.

As imagens possuem fundo transparente e foram produzidas para uso sobre os painéis escuros do frontend.
