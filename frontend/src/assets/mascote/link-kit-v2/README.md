# Link — Kit oficial v2

Mascote oficial da plataforma PingLevel.

## Regra visual B+C

- **Modo padrão:** coroa limpa, sem antena física e sem holograma.
- **Pensando/analisando:** holograma de rede ativo.
- **Alerta:** holograma com conexão interrompida.

## Arquivos

- `link-v2-principal.png` — pose neutra de corpo inteiro.
- `link-v2-ensinando.png` — apresentação de conteúdo.
- `link-v2-pensando-holograma.png` — tutor/RAG processando.
- `link-v2-comemorando.png` — conclusão e conquista.
- `link-v2-alerta-holograma.png` — erro ou atenção de rede.
- `link-v2-avatar.png` — avatar mestre quadrado.
- `link-v2-avatar-512.png`, `256.png` e `128.png` — avatares para interface.

Todos os PNGs possuem fundo transparente validado.
