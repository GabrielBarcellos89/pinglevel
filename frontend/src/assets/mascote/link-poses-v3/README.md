# Link — dez expressões e poses

Variações criadas com referência na arte principal do mascote existente no projeto PingLevel. Mantidos o robô preto, detalhes vermelhos, olhos luminosos e símbolo de rede no peito. As poses são novas gerações, com possíveis pequenas variações de detalhes de renderização.

## Conteúdo

- `png/`: dez originais de 1024 × 1536 px com canal alpha transparente.
- `webp/`: as mesmas artes otimizadas, preservando transparência.
- `webp-512/`: versões de 512 × 768 px para interface.
- `PREVIA.jpg`: catálogo das dez poses sobre fundo escuro.
- `manifesto.json`: relação dos arquivos.
- `PROMPTS.md`: direção e descrições usadas.

Não há textos ou balões incorporados às artes. Use texto HTML para as falas do tutor. Não há alteração de código ou implantação neste pacote.

## Poses e sugestões de uso

1. Descontraído — boas-vindas ou intervalo.
2. Pensativo — convite a formular uma hipótese.
3. Sem entender — pedido gentil de esclarecimento, sem reprovar o aluno.
4. Curioso — convite à observação da topologia.
5. Comemorando — resultado ou etapa concluída.
6. Explicando — explicação ou referência.
7. Incentivando — apoio após tentativa.
8. Investigando — análise de evidências de rede.
9. Surpreso — descoberta ou resultado inesperado.
10. Aguardando — esperando a ação do aluno.

As expressões apoiam a comunicação, mas não substituem mensagens explícitas de resultado. Exibir uma pose de sucesso deve depender da validação real do laboratório.
