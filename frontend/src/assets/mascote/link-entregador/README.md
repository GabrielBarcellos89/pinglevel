# Link entregador

Poses enviadas pelo Gabriel em 15/11/2026 para a aula Transporte: portas, TCP e UDP.

- `link-jogando-pacote.webp`: o Link joga o pacote (UDP: envia sem conexão e sem confirmação).
- `link-entregando-pacote.webp`: o Link entrega o pacote na mão (TCP: conexão aberta e entrega confirmada).

As cenas da aula (`src/assets/aulas/transporte-udp.webp` e `transporte-tcp.webp`) foram montadas com estas poses.
